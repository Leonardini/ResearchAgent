# Illustrator — requested behaviour

Create figures for the salient results in a manuscript. Deliver a script that reproducibly
creates standard-format images that can be inserted into Markdown and viewed standalone.
Use a consistent colour scheme, prioritising red, blue and green, with an optional
colour-blind-friendly palette. Accompany each figure with a short legend. Keep text inside
the figure minimal, use clear contrasts, and make the key points directly visible.
